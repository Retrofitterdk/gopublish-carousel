# Go:Publish Carousel

A looping carousel block for WordPress. Each slide can hold any blocks. The carousel is rendered on the server and runs on the [Interactivity API](https://developer.wordpress.org/block-editor/reference-guides/interactivity-api/), with no jQuery or third-party slider library.

- **Requires:** WordPress 6.6+, PHP 7.2+
- **License:** GPL-2.0-or-later
- **Changelog and user FAQ:** see [readme.txt](readme.txt)

## Features

- Slides (`gopublish/carousel-slide`) can contain any blocks.
- 1–6 slides visible at once, with a configurable number of slides to scroll.
- Optional cutoff effect: the last visible slide is partly shown.
- Separate slide width on mobile (below 782 px).
- Endless looping, previous/next buttons, touch swipe and mouse drag.
- Navigation is hidden when all slides fit in view.
- Wide/full alignment, spacing and minimum height support.

## Installation

**From a zip:** upload it under Plugins → Add New → Upload Plugin, then activate it.

**From source:**

```bash
git clone https://github.com/Retrofitterdk/gopublish-carousel.git
cd gopublish-carousel
npm install
npm run build
```

Then activate the plugin in WordPress. The compiled files in `build/` are what WordPress loads.

## Development

```bash
npm start              # Build and watch for changes
npm run build          # Production build
npm run lint:js        # Lint JavaScript
npm run lint:css       # Lint styles

```

PHP coding standards (requires `composer install` first):

```bash
npm run lint:php       # phpcs
npm run lint:php:fix   # phpcbf
```

To create a translation template, use WP-CLI. It reads PHP, JavaScript and `block.json`:

```bash
wp i18n make-pot . languages/gopublish-carousel.pot --exclude=node_modules,src
```

### Project structure

```
gopublish-carousel.php     Plugin bootstrap: block registration and inner-block render helper
src/carousel/              Carousel block (dynamic: render.php + view.js)
src/carousel-slide/        Carousel Slide block (static wrapper, only allowed inside a Carousel)
build/                     Compiled output (generated by npm run build)
```

See [src/README.md](src/README.md) for what each source file does.

### How it works

- **Rendering:** the carousel is a dynamic block registered with `skip_inner_blocks`. `render.php` renders each slide once with `gopublish_carousel_render_inner_block()`, which applies the same filters and block context as core. The output includes the navigation, the slides and the clones used for seamless looping.
- **State:** each carousel's settings and position live in its `data-wp-context`. One store, `gopublish-carousel` in `view.js`, handles every carousel on the page, and directives such as `data-wp-on--click="actions.moveForward"` resolve to the carousel they sit in.
- **Looping:** the slides are repeated cyclically as clones before and after the real slides. After sliding onto a clone, the track jumps back to the matching real slide without animation.

### Styling

The navigation is styled with CSS custom properties on `.wp-block-gopublish-carousel`, for example:

```css
.wp-block-gopublish-carousel {
	--nav-button-background-hover: #1e1e1e;
	--nav-container-justify-content: center;
}
```
